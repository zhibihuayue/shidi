# 定位容器

<font color="#FF0000">该组件为内部组件，不应该暴露给外部业务开发使用。</font>

这个容器用于锚定于某一个页面元素（如：工具箱小工具的“弹窗”、告警详情的处置弹窗、设备树的基础容器等）固定位置的容器。
这个容器通常不可拖拽、视为父元素的子元素。与纯粹在整个窗口上展示的“dialog 弹窗”场景不同。

### 自定义样式风格

<font color="#FF0000">specialStyle : 用于自定义样式风格</font>
<br/>
<br/>
<font >类型 : Any </font> |
<font >默认值 : 无</font>
<br/>
<br/>
<font color="#FF0000">传递形式如下 :</font>

     对象形式:
     {
          // 通用主题配置，作用于全部主题
            striped: true ,                                                                                              |
           // 通用主题配置
           wiseblue: {
             striped: false //条纹底色标题（自定义风格）
           },
           // 林业主题配置
           aquamarine: {
             striped: false //条纹底色标题（自定义风格）
           },
           // 国土主题配置
           terracotta: {
             striped: false //条纹底色标题（自定义风格）
           }
     }
     数组形式:
     [
          // 通用主题配置，作用于全部主题
          { striped: true },
          {
            wiseblue: {
              striped: false //条纹底色标题（自定义风格）
            }
          },
          // 林业主题配置
          {
            aquamarine: {
              striped: false //条纹底色标题（自定义风格）
            }
          },
          // 国土主题配置
          {
            terracotta: {
              striped: false //条纹底色标题（自定义风格）
            }
          }
     ]

### 事件

<font color="#FF0000">标红的事件名代表这是个总线事件，请使用 globalEventBus 监听</font>

| 事件名 | 事件参数类型 | 示例值 | 说明               |
| ------ | ------------ | ------ | ------------------ |
| close  | void         | 无     | 点击关闭按钮时派发 |

### 插槽

| 插槽名   | 插槽参数类型 | 示例值 | 说明                                                                                 |
| -------- | ------------ | ------ | ------------------------------------------------------------------------------------ |
| 默认插槽 | void         | 无     | 容器 body 内可承载任意元素                                                           |
| extra    | void         | 无     | 标题区域的右侧。注意，如果没有配置 title，这个插槽也没有意义（因为 header 不存在）。 |
| title    | void         | 无     | 自定义渲染整个标题文字区域。                                                         |
