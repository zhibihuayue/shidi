# 林区卡口列表组件

展示卡口摄像机列表并播放卡口摄像机通道。

卡口摄像机与普通摄像机有所差别，视为单独的图层进行处理。点击卡口摄像机列表上的选项，会定位到对应的卡口摄像机位置。

## API

### 属性

| 参数         | 类型             | 默认值     | 说明                                                                                                                                                                                                            | 版本   |
| ------------ | ---------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| mapId        | `string`         | `mapId`    | 对应的地图 ID，与其他组件一致                                                                                                                                                                                   | 1.6.80 |
| title        | `string`         | `林区卡口` | 卡片标题文字                                                                                                                                                                                                    | 1.6.80 |
| subtitle     | `string`         | `林区卡口` | 设备列表折叠卡片标题文字                                                                                                                                                                                        | 1.6.80 |
| viewModeKey  | `string`         | ''         | 用于记录是卡片视图还是列表视图的用户记忆 key，外部如有需要请覆盖为别的键。传空为不使用用户记忆。                                                                                                                | 1.6.80 |
| expandKey    | `string`         | ''         | 用于记录设备树展开模式的用户记忆 key，外部如有需要请覆盖为别的键。传空为不使用用户记忆。                                                                                                                        | 1.6.80 |
| videoModeKey | `string`         | ''         | 用于记录视频播放模式的用户记忆 key，外部如有需要请覆盖为别的键。传空为不使用用户记忆。                                                                                                                          | 1.6.80 |
| layersId     | `Number`         | 空         | 卡口摄像机图层 id。这个参数控制打点交互，如果传入了该配置，则是在当前大屏的对应 id 图层内操作；否则，该组件会尝试自己进行打点。**注意，如果传入该值，必须在当前大屏的图层管理里存在这个图层，否则会工作不正常** | 1.6.80 |
| cardBg       | `String或Object` | 'wetland'  | 卡片图标。默认自带的配置是`forest`和`wetland`，分别是林区和湿地的卡片图。可以自定义成其他图片，如果要自定义成其他图片，传一个格式为{ url, selectUrl }的对象                                                     | 1.6.80 |

### 事件

- 组件内监听全局事件

| 事件名称                                    | 说明                                                                                                                                                                                          | 回调参数 |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| common-comp-forest-gateway-camera\_\_resize | 供外部使用，如果外部主动操作内部高度发生变化后需要触发，因为内部的 scrollbar 不能直接响应外部高度变化（浏览器窗口的放大/缩小没有问题，这个问题局限于外部 dom 主动限高的情况），需求手动更新。 | 无       |

- 组件内抛出全局事件

| 事件名称                                | 说明                               | 回调参数        |
| --------------------------------------- | ---------------------------------- | --------------- |
| common-comp-snap-list\_\_visible-filter | 与实时抓拍列表联动，关联事件功能。 | { keywords: '', |

        channelCodes: [],
        queryStartTime: '',
        queryEndTime: '' } |

- 组件本地事件
  | 事件名称 | 说明 | 回调参数 |
  | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
