## API

### Props

| 参数                      | 类型    | 默认值 | 说明                     |
| ------------------------- | ------- | ------ | ------------------------ |
| show-close                | Boolean | `true` | 是否显示关闭按钮         |
| show-header               | Boolean | `true` | 是否显示头部信息         |
| show-aquamarine-line      | Boolean | `true` | 是否显示璧山绿 line 样式 |
| show-terracotta-line      | Boolean | `true` | 是否显示赤土黄 line 样式 |
| show-terracotta-corner    | Boolean | `true` | 是否显示赤土黄倒角       |
| is-aquamarine-line-center | Boolean | `true` | 璧山绿 line 是否居中     |
