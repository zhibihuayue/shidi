## 基础地图

该地图用于承载大屏底部地图的呈现，作为大屏的地图复用单元。
本组件是地图包的一个托管封装，它**不享有自己的地图 API**，仅仅是在内部使用地图进行初始化。
其初始化的地图实例会送入 mapRef，通过对应的 mapId 在 mapRef 中获取地图实例也可以直接使用地图 API 操作该地图的表现。

**注意：本组件从 1.7.00 开始自带一个@ct/ct_map_ol 包，并会自行往 window['@ct/ct_map_ol']上挂载 CTMapOl 类，集成方使用时不再需要自己挂载地图版本，而使用地图包的 API 也需要通过此引用调用**

## API

### 属性

| 参数               | 类型      | 默认值                                | 说明                                                                                                                                                                                      | 版本   |
| ------------------ | --------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| mapId              | `string`  | `mapId`                               | 初始化地图的 domId。这也会作为地图实例 ID，请注意整个大屏上不应出现重复 ID。                                                                                                              | 1.6.50 |
| chooseMapMemoryKey | `string`  | `chooseMap`                           | 地图模式切换记忆 Key，保存当前选择的贴图模式。如果为空，则不会保存用户记忆。                                                                                                              | 1.6.50 |
| mapToolElement     | `string`  | ``                                    | 将地图工具转移到指定元素上，用于集成方调整层级                                                                                                                                            | 1.6.50 |
| mapMouseElement    | `string`  | ``                                    | 将 showMouseLocation 的经纬度元素转移到指定元素上，用于集成方调整层级                                                                                                                     | 1.6.80 |
| showMouseLocation  | `boolean` | `false`                               | 在右下角显示当前鼠标经纬度位置，默认不开启。                                                                                                                                              | 1.6.70 |
| showMapControl     | `boolean` | `true`                                | 初始化完成后，是否在右下角显示地图切换、比例尺工具。默认开启。**该配置项为一次性参数，非受控属性。初始化后再修改不会生效；即使隐藏，依然会被联动事件**                                    | 1.6.80 |
| defaultTileMode    | `number`  | `1`                                   | 默认情况下的地图类型。默认使用 1 卫星地图。0、1、2、3 分别代表 常规地图、卫星地图、三维地形图、二维地形图，不可为空。                                                                     | 1.6.80 |
| minZoom            | `number`  | `4`                                   | 默认情况下的地图最小缩放等级。                                                                                                                                                            | 1.6.80 |
| maxZoom            | `number`  | `18`                                  | 默认情况下的地图最大缩放等级。                                                                                                                                                            | 1.6.80 |
| tileModes          | `Array`   | `[0, 1, 2, 3]`                        | 定义可供切换的地图类型。0、1、2、3 分别代表 常规地图、卫星地图、三维地形图、二维地形图。默认启用全部。不可以为空数组，这个数组的长度至少要为 1，如果是空数组将无法正常工作。              | 1.6.80 |
| listenGlobalEvent  | `boolean` | `true`                                | 是否监听其他全局事件。如果为 false，则不会监听与工具箱地图控制按钮的联动（不监听 map-control-show）                                                                                       | 1.6.80 |
| resolveEventName   | `string`  | `common-comp-map\_\_init-map-resolve` | 地图初始化时候的事件名。如果传递为空值，则在对应时刻不会派发事件。                                                                                                                        | 1.6.80 |
| noControl          | `boolean` | `false`                               | 是否完全禁用地图控制器实例，与 showMapControl 不同的是，showMapControl 只控制显隐，对应控制器依然会被初始化。用于解决一个页面上同时存在多个地图时，会出现重复初始化地图控制器实例的问题。 | 1.7.00 |

### 事件

- 组件内抛出事件

| 事件名称                            | 说明                                                                                                                                                                                                                                                                     | 回调参数         |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------- |
| common-comp-map\_\_init-map-resolve | **该事件名可以被 props 里的 resolveEventName 配置，这里写的事件名是默认值。**地图初始化成功后返回状态，**注意，切换地图模式也会触发该事件。**事件参数的 status 表示本次事件的地图实例是否初始化完毕，为`true`时才意味着真正初始化完毕，`false`时为一次地图新发起初始化。 | {status:Boolean} |

- 组件内监听事件

| 事件名称                            | 说明                                                                                                                                                                                                                     | 回调参数                       |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------ |
| common-comp-map\_\_map-control-show | 显示/隐藏地图类型切换、比例尺控制工具的显示。事件参数的 mapId 表示这次事件的目标地图 id 是哪个，需要与期望的基础地图的 mapId 相同，如果不传的话，认为对所有地图实例都生效。 status 表示本次是显示还是隐藏，true 为显示。 | {mapId:String, status:Boolean} |
