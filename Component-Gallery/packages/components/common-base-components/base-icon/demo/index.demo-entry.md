## API

### Props

| 参数        | 类型    | 默认值  | 说明                                      |
| ----------- | ------- | ------- | ----------------------------------------- |
| iconClass   | String  | ``      | 显示 Icon 的图标 class,基于 iconfont 资源 |
| activeClass | String  | ``      | Icon 点击高亮的图标                       |
| iconStyle   | String  | ``      | iconStyle 的样式                          |
| disabled    | Boolean | `false` | 禁用功能                                  |
