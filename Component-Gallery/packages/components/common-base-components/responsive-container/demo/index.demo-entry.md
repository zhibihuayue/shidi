# 定位容器

这个容器用于锚定于某一个页面元素（如：工具箱小工具的“弹窗”、告警详情的处置弹窗、设备树的基础容器等）固定位置的容器。
这个容器不可拖拽、视为父元素的子元素。

```demo
basic.vue
```

## API

### Props

| 参数                | 类型    | 默认值        | 说明                                                                                                                                                |
| ------------------- | ------- | ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| left                | Number  | `undefined`   | 左偏移量。这个组件是 absolute 定位，等效于同名 css 属性。<br>**会参与 pxToRem 计算，所以请注意传入的是基于 1920X1080 分辨率下的数值。**             |
| right               | Number  | `undefined`   | 右偏移量。这个组件是 absolute 定位，等效于同名 css 属性。<br>**会参与 pxToRem 计算，所以请注意传入的是基于 1920X1080 分辨率下的数值。**             |
| top                 | Number  | `undefined`   | 上偏移量。这个组件是 absolute 定位，等效于同名 css 属性。<br>**会参与 pxToRem 计算，所以请注意传入的是基于 1920X1080 分辨率下的数值。**             |
| bottom              | Number  | `undefined`   | 下偏移量。这个组件是 absolute 定位，等效于同名 css 属性。<br>**会参与 pxToRem 计算，所以请注意传入的是基于 1920X1080 分辨率下的数值。**             |
| width               | Number  | `undefined`   | 宽度，等效于同名 css 属性，如果没有配置，则是按内容元素自动撑开宽度。<br>**会参与 pxToRem 计算，所以请注意传入的是基于 1920X1080 分辨率下的数值。** |
| height              | Number  | `undefined`   | 高度，等效于同名 css 属性，如果没有配置，则是按内容元素自动撑开高度。<br>**会参与 pxToRem 计算，所以请注意传入的是基于 1920X1080 分辨率下的数值。** |
| can-close           | Boolean | `false`       | 是否显示关闭按钮。点击关闭按钮会派发`close`事件                                                                                                     |
| industry-class      | String  | `common-iw-s` | 内置的基础组件主题类名。这个类名会影响容器内的基础 UI 组件，通常不需要修改。<br>如果希望移除此系列样式，可修改为别的 class 名或传入空字符串。       |
| headTitle           | String  | ''            | 标题。如果没有配置标题（空字符串也算没有配置），那么不仅是标题文字为空，标题区域（header）整个都不会出现。                                          |
| highlight-title     | Boolean | `true`        | 标题（header 部分）是否用存在底色、加粗的高亮方法呈现                                                                                               |
| left-title          | Boolean | `false`       | 标题是否左对齐展示样式。默认的标题是居中展示的。                                                                                                    |
| stop-mousedown-body | Boolean | `true`        | 是否默认阻止 容器 层的事件冒泡。这个 props 一般是用来避免拖拽误操作用的，默认是拦截全部                                                             |
| stop-mousedown-body | Boolean | `true`        | 是否默认阻止 容器 层的事件冒泡。这个 props 一般是用来避免拖拽误操作用的，默认是拦截全部                                                             |
| canCollapse         | Boolean | `true`        | 是否折叠                                                                                                                                            |

### 事件

| 事件名 | 事件参数类型 | 示例值     | 说明               |
| ------ | ------------ | ---------- | ------------------ |
| close  | void         | 无         | 点击关闭按钮时派发 |
| toggle | Boolean      | true/false | 点击折叠按钮时派发 |

### 插槽

| 插槽名   | 插槽参数类型 | 示例值 | 说明                                                                                 |
| -------- | ------------ | ------ | ------------------------------------------------------------------------------------ |
| 默认插槽 | void         | 无     | 容器 body 内可承载任意元素                                                           |
| extra    | void         | 无     | 标题区域的右侧。注意，如果没有配置 title，这个插槽也没有意义（因为 header 不存在）。 |
| title    | void         | 无     | 自定义渲染整个标题文字区域。                                                         |
