# 通用按钮组件

支持换肤的按钮组件

## 代码演示

```demo
basic.vue
```

## API

### Props

| 参数 | 类型   | 可选值                              | 默认值    | 说明     |
| ---- | ------ | ----------------------------------- | --------- | -------- |
| type | String | `primary / default / danger / tiny` | `default` | 按钮类型 |

### Event

| 事件名 | 事件参数类型 | 示例值 | 说明     |
| ------ | ------------ | ------ | -------- |
| click  | event        | 无     | 点击事件 |

### 插槽

| 插槽名   | 插槽参数类型 | 示例值 | 说明     |
| -------- | ------------ | ------ | -------- |
| 默认插槽 | void         | 无     | 按钮内容 |
