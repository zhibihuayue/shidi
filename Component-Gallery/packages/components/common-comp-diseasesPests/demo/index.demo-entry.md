## EvnetBus 事件

- 组件监听事件

  | 事件名称                              | 说明             | 回调参数 | 参数说明             |
  | ------------------------------------- | ---------------- | -------- | -------------------- |

  | commonCompDiseasesPests_setInsectPestDetailsShow |  监听是否点击了图斑  |  Boolean |  false 或者 true       |

  | commonCompDiseasesPests_detailPopShow |  监听详情弹窗隐藏显示 |   Boolean |  false 或者 true |

  | commonCompDiseasesPests_changeDetail |  监听点击了折线图改变了详情数据  |  Boolean |  false 或者 true    |

  ## 组件参数
  
  componentName：组件title名称-默认病虫害预测
